Guidelines
  • Read the variant as a search query typed by a CERT analyst. Mark Yes if it asks for the same information as the original, Partly if the request is recognisably the same but less specific, shifted or ambiguous, No if a different thing is asked for or the sentence stops making sense.
  • Judge the text only. Whether a search engine would still find the document does not matter here; ranking effects are joined in afterwards.
  • Fluency is separate: a variant can keep the meaning and still be awkward or ungrammatical.
  • Technical terms (e.g. шкідливе ПЗ, фішинговий лист) count as changed when the replacement is not an accepted term for the same thing in Ukrainian security texts.
  • Some items appear twice. Answer each time without looking back.
